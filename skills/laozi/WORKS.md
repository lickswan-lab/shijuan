# 老子 · 文献结构与版本层

> **本 skill 处理的"老子"是一个文本现象，不是一个确证的个人。**
> 本文件先讲清"《道德经》是什么"——有几层文本、怎么传下来、学者怎么断代——再讲各章主题归类。扮演者被问到"你是谁写的"时，应当从此处的考据材料出发作答，**不假装史记描述是定论**。

---

## 0. 文本层次（从最早到主流）

### 0.1 郭店楚简《老子》(∼ 前 300 BCE，最早物证)

- **出土**：1993 年湖北荆门郭店一号楚墓，竹简 804 枚，其中《老子》相关 71 枚
- **结构**：分甲、乙、丙三组（非通行本 81 章结构），甲组 39 枚、乙组 18 枚、丙组 14 枚
- **字数**：约 2000 字（通行本约 5000 字），**只占通行本三分之一多一点**
- **重大意义**：
  - 证明《老子》前 300 BCE 已在楚地流传——推翻了"《老子》晚出于《庄子》"的疑古派观点（罗根泽、钱穆等）
  - **但三组内容加起来也不是完整 81 章**——说明当时《老子》仍在生长中、没有定型
- **与通行本差异（关键 5 处）**：
  1. **第十九章**：通行本"绝圣弃智 / 绝仁弃义 / 绝巧弃利"——郭店甲组作"絕智棄辯 / 絕巧棄利 / 絕僞棄詐"。**没有反仁义**。这是 CONTROVERSIES.md 必须展开的核心问题
  2. **第一章** 通行本开篇"道可道非常道"——郭店本**没有**对应段落（郭店本中可能尚未作为开篇）
  3. **许多"反儒"强度更高的章节**——在郭店本中要么没有、要么语气温和
  4. 郭店本很多字用假借——与今本的训读有出入
  5. 郭店丙组混有《太一生水》——可能是另一宇宙论文本附入

### 0.2 马王堆帛书《老子》(∼ 前 168 BCE)

- **出土**：1973 年湖南长沙马王堆三号汉墓（轪侯利苍之子墓）
- **版本**：甲本（无避讳，约前 200 BCE）、乙本（避刘邦讳而不避惠帝刘盈、文帝刘恒，约前 180 BCE）
- **结构突破**：**德经在前，道经在后**——与通行本**相反**
  - 即：今日通行本第 38 章"上德不德"在马王堆本是**第一章**
  - 支持"《老子》本名《德道经》"一说
  - 韩非子《解老篇》的引用顺序也是德经先——与马王堆一致
- **章数**：大致与通行本 81 章对应，但**无分章符**——章的划分是后世注家所为
- **文字差异**：字句差异远多于郭店本（因马王堆本接近"定型期"）——但很多关键概念的表述已经和今本相同

### 0.3 北大汉简《老子》(汉初)

- 2009 年北京大学收藏流散海外的西汉竹简，其中《老子》残简保存较完整，属于"德经在前"系统，与马王堆乙本接近
- 证明"德道经"结构在汉初是通行版本
- 有 77 章分章符——最早的分章文本

### 0.4 严遵《老子指归》 (西汉末，∼ 前 50-0 BCE)

- 成都隐士严遵（庄遵）的注解——现存残本 7 卷（原 13 卷，德经部分残失过半）
- **哲学倾向**：重玄学雏形、融合黄老与易学
- **引文依据**：严遵所见本仍是"德经在前"

### 0.5 河上公《老子章句》(东汉，托名，约 2-3 世纪）

- 传统说"河上公"是汉文帝时方士，现代学者多认定为东汉末至魏晋间托名
- **结构创新**：分 81 章、**道经在前德经在后**，给每章加了章名（如"体道第一""养身第二"）
- **解读倾向**：**养生道教化**——把老子读成一本修身养气的手册（把"谷神不死"读成体内的脏腑神灵）
- 这是**道教用老子**的关键文本——葛洪、陶弘景、成玄英都走这条线

### 0.6 王弼《老子注》(曹魏，226-249)

- **王弼** (226-249)，早慧的魏晋玄学家，23 岁就死了，但已留下《老子注》《周易注》《老子指略》
- **文本地位**：今日**通行本** = 王弼注本（81 章、道德经结构）
- **解读倾向**：**哲学玄学化**——不讲养生、讲"以无为本"、"崇本息末"、"得意忘言"
- 王弼引老以注《易》、注《论语》——开启魏晋"儒道合流"的玄学潮流
- **扮演注意**：今天我们背的"道可道非常道"这句分章、这句句读——是王弼给的。老子本人有无"第一章"概念都不确定

### 0.7 傅奕校定《道德经古本篇》 (唐初，579-644)

- 傅奕据六朝古本校定——保留一些不同异文，常被陈鼓应、刘笑敢作为校勘重要参照

## 1. 八十一章的主题归类

以王弼通行本章序为准。不是所有章都能干净归入一类——很多章混杂。下面的归类是**扮演时调用的索引**，便于按问题类型找对应章节。

### 1.1 道论 · 宇宙论（14 章左右）

**核心章**：

- **第一章**（道可道，非常道）——"无名天地之始，有名万物之母"——道的不可言说性 + 有无双重命名
- **第四章**（道冲而用之）——"挫其锐，解其纷，和其光，同其尘"——道的虚冲
- **第六章**（谷神不死）——"玄牝之门，是谓天地根"——女性化的生成原型
- **第十四章**（视之不见名曰夷）——夷希微三者混而为一——道的超感官性
- **第二十一章**（孔德之容）——"恍兮惚兮，其中有象；惚兮恍兮，其中有物"——道体的恍惚
- **第二十五章**（有物混成）——"人法地，地法天，天法道，道法自然"——四层法则序列
- **第三十二章**（道常无名）——朴 / 始制有名
- **第三十四章**（大道泛兮）——道的普遍泛在
- **第四十章**（反者道之动，弱者道之用）——**道的运动规律最浓缩表述**
- **第四十二章**（道生一，一生二，二生三，三生万物）——生成论
- **第五十一章**（道生之，德畜之）——道德分工

### 1.2 德论 · 个人修养（20 章左右）

- **第八章**（上善若水）——**最著名的"若"式比喻**：水七善（居善地、心善渊、与善仁、言善信、正善治、事善能、动善时）
- **第九章**（持而盈之不如其已）——功遂身退
- **第十章**（载营魄抱一）——"专气致柔，能婴儿乎"——婴儿态理想
- **第十三章**（宠辱若惊）——身为患之根本
- **第十五章**（古之善为士者）——豫焉若冬涉川 / 俨兮其若客（善为道者的七种状态）
- **第十六章**（致虚极，守静笃）——虚静论 + "归根曰静"
- **第二十章**（绝学无忧）——"我愚人之心也哉"——反智的自我
- **第二十二章**（曲则全，枉则直）——"不自见故明"——六"不"
- **第二十三章**（希言自然）——飘风骤雨不能久
- **第三十三章**（知人者智，自知者明）——**内知的优先**
- **第四十四章**（名与身孰亲）——知足不辱
- **第五十五章**（含德之厚比于赤子）——赤子不咬不爪
- **第五十六章**（知者不言，言者不知）——"和其光，同其尘，是谓玄同"
- **第六十七章**（天下皆谓我道大）——**三宝章**："一曰慈，二曰俭，三曰不敢为天下先"
- **第七十三章**（勇于敢则杀，勇于不敢则活）——两种勇
- **第七十六章**（人之生也柔弱）——柔弱胜刚强的身体隐喻

### 1.3 政治论 · 治国（25 章左右）

- **第三章**（不尚贤，使民不争）——反精英主义
- **第十七章**（太上，下知有之）——四等君主论
- **第十八章**（大道废，有仁义）——**对儒家道德的结构性解构**
- **第十九章**（绝圣弃智 / 绝仁弃义）——通行本 vs 郭店本差异最大章
- **第二十六章**（重为轻根）——君主守重守静
- **第二十九章**（将欲取天下而为之）——天下神器不可为
- **第三十章**（以道佐人主者，不以兵强天下）——反战
- **第三十一章**（夫兵者不祥之器）——最强烈的反战章
- **第三十六章**（将欲歙之，必固张之）——**常被法家化引用**的"微明"章——"柔弱胜刚强。鱼不可脱于渊，国之利器不可以示人"
- **第三十七章**（道常无为而无不为）——**道经的结尾命题**
- **第三十八章**（上德不德）——**德经的开篇命题**——"失道而后德，失德而后仁，失仁而后义，失义而后礼"
- **第五十七章**（以正治国，以奇用兵，以无事取天下）
- **第五十八章**（其政闷闷，其民淳淳；其政察察，其民缺缺）——反明察政治
- **第五十九章**（治人事天莫若啬）——啬的政治论
- **第六十章**（治大国若烹小鲜）——不折腾原则
- **第六十一章**（大国者下流）——大国的谦卑
- **第六十五章**（古之善为道者，非以明民，将以愚之）——**最刺眼的一句**：愚民？
- **第六十六章**（江海所以能为百谷王者，以其善下之）
- **第七十四章**（民不畏死，奈何以死惧之）
- **第七十五章**（民之饥，以其上食税之多）——很罕见的民生批判
- **第七十七章**（天之道其犹张弓与）——天道的均平
- **第七十八章**（天下莫柔弱于水）——水之悖论
- **第八十章**（小国寡民）——**理想社会图景**——老死不相往来
- **第八十一章**（信言不美，美言不信）——篇末的自反式结尾

### 1.4 认识论（8 章左右）

- **第一章**——道不可道
- **第二章**（天下皆知美之为美斯恶矣）——**相反概念相生**论："有无相生"
- **第十一章**（三十辐共一毂）——**无之用**章："故有之以为利，无之以为用"
- **第十二章**（五色令人目盲）——感官批判
- **第四十一章**（上士闻道，勤而行之）——三等闻道者
- **第四十三章**（天下之至柔驰骋天下之至坚）——无有入无间
- **第四十七章**（不出户知天下）——内省优先于外求
- **第四十八章**（为学日益，为道日损）——**知识论最浓缩**
- **第七十章**（吾言甚易知，甚易行）——他自称："知我者希，则我者贵"

### 1.5 战争与处世（5 章左右）

- 第三十章、第三十一章（已见政治论）
- **第六十八章**（善为士者不武）——四善
- **第六十九章**（用兵有言：吾不敢为主而为客）——**后人化用"哀兵必胜"**
- 第七十六章（已见德论）

## 2. 关键原文锚点（扮演时最常调用）

### 2.1 道论锚（必须能准确引）

- **第一章** "道可道，非常道。名可名，非常名。无名天地之始，有名万物之母。故常无欲以观其妙，常有欲以观其徼。此两者同出而异名，同谓之玄。玄之又玄，众妙之门。"
- **第二十五章** "有物混成，先天地生。寂兮寥兮，独立不改，周行而不殆，可以为天下母。吾不知其名，字之曰道，强为之名曰大。……人法地，地法天，天法道，道法自然。"
- **第四十章** "反者道之动，弱者道之用。天下万物生于有，有生于无。"（全章**仅 21 字**——通行本最短章，**道家宇宙论的浓缩**）
- **第四十二章** "道生一，一生二，二生三，三生万物。万物负阴而抱阳，冲气以为和。"

### 2.2 德论锚

- **第八章** "上善若水。水善利万物而不争，处众人之所恶，故几于道。……夫唯不争，故无尤。"
- **第十六章** "致虚极，守静笃。万物并作，吾以观复。……归根曰静，静曰复命。"
- **第三十三章** "知人者智，自知者明。胜人者有力，自胜者强。知足者富，强行者有志。"
- **第六十七章** "我有三宝，持而保之：一曰慈，二曰俭，三曰不敢为天下先。"

### 2.3 政治锚

- **第三十八章** "上德不德，是以有德；下德不失德，是以无德。……故失道而后德，失德而后仁，失仁而后义，失义而后礼。夫礼者，忠信之薄而乱之首。"
- **第六十章** "治大国若烹小鲜。"（王弼注：烹小鱼不可搅动太多，**多搅则鱼烂**）
- **第八十章** "小国寡民。使有什伯之器而不用；使民重死而不远徙。虽有舟舆，无所乘之；虽有甲兵，无所陈之。使民复结绳而用之。甘其食，美其服，安其居，乐其俗。邻国相望，鸡犬之声相闻，民至老死不相往来。"

### 2.4 认识论锚

- **第十一章** "三十辐共一毂，当其无，有车之用。埏埴以为器，当其无，有器之用。凿户牖以为室，当其无，有室之用。故有之以为利，无之以为用。"
- **第四十八章** "为学日益，为道日损。损之又损，以至于无为。无为而无不为。"

### 2.5 悖论锚（"正言若反"代表作）

- **第四十一章** "明道若昧，进道若退，夷道若类。上德若谷，大白若辱，广德若不足，建德若偷，质真若渝，大方无隅，大器晚成，大音希声，大象无形，道隐无名。"
- **第四十五章** "大成若缺，其用不弊。大盈若冲，其用不穷。大直若屈，大巧若拙，大辩若讷。"
- **第七十八章** "天下莫柔弱于水，而攻坚强者莫之能胜……弱之胜强，柔之胜刚，天下莫不知，莫能行……正言若反。"

## 3. 老子三说的史料辨析（《史记·老子韩非列传》）

司马迁（前 145-前 86）在《史记·卷六十三》给"老子"立传——但他本人**已经不确定老子是谁**。传中并列三种"老子"：

### 3.1 第一说：老聃（李耳，字伯阳）

- 楚国苦县厉乡曲仁里人（今河南鹿邑）
- 姓李氏，名耳，字聃，一字伯阳
- 周室守藏室之史（国家图书馆管理员）
- 孔子曾问礼于老聃——孔子出后叹曰："吾今日见老子，其犹龙邪！"
- 周衰，老子西出函谷关——关令尹喜请留书——乃著上下篇五千言
- **然后"莫知其所终"**

### 3.2 第二说：老莱子

- 楚人，作书十五篇
- "与孔子同时云"——司马迁自己的口气就不肯定
- **与老聃是两个人还是一个人？** 司马迁没给定论

### 3.3 第三说：太史儋

- 周太史儋，见秦献公（前 385-前 362 在位）
- **距孔子死 129 年**
- 司马迁记："或曰儋即老子，或曰非也，世莫知其然否。"

### 3.4 司马迁的结论

- 司马迁说："老子，隐君子也。"
- 最后加一句："世之学老子者，则绌儒学；儒学亦绌老子。'道不同不相为谋'，岂谓是邪？"
- **司马迁本人写下"世莫知其然否"——他在前汉都搞不清**

### 3.5 现代学界的主流判断

- **"老子"这个名字很可能不指一个历史个体**——是一个文本传统的人格化
- 《道德经》的成书至少经历：春秋末的格言集成 → 战国中期的思想整合（可能由某个或某些"老聃派"学者完成）→ 战国末/秦汉之际的定型
- 孔子见老聃很可能是早期儒道论战时**道家方面**为抬高本派声望而构造的传说——《庄子》外篇借此造出多则故事（虽然外篇非庄子亲笔）
- 刘笑敢《老子古今》(2006) 等代表当代校勘立场：承认不能精确定位"老子其人"，但可以讨论**文本层次的生成**

## 4. 《庄子》对老聃的描写

《庄子》（内七篇可能是庄周亲笔，约前 4 世纪中晚期；外、杂篇后学手笔，前 3 世纪）多次写老聃。**这是最早的"老聃形象"证据之一**，但已经小说化。

- **《德充符》** 写孔子向老聃自白"天刑之"——展示老聃作为孔子的精神高位者
- **《天地》** 写"黄帝遗玄珠"寓言——罔象（无象）得之——符合老子"无名"旨趣
- **《天道》** 写孔子西藏十二经以说老聃——老聃打断："太谩！"
- **《知北游》** 写"道在蝼蚁""道在稊稗""道在屎溺"——把老子的"道泛在"推到极端
- **《天下》篇**（杂篇之末，道家学派史）给老聃的定位：
  - "以本为精，以物为粗，以有积为不足，澹然独与神明居"
  - 列在关尹、老聃条下——**把关尹和老聃并列**——说明那个时代"老子"可能是学派名而不是单人名
  - 评语："建之以常无有，主之以太一，以濡弱谦下为表，以空虚不毁万物为实。"
  - **这是庄子学派给老子学派的"思想摘要"——极准确**

## 5. 《韩非子·解老/喻老》

韩非 (约前 280-前 233) 是现存**最早的《老子》注释**。

- **《解老篇》** 逐段解释部分章节——但只解"德经"部分——**证明韩非所见本是"德经在前"**
- **《喻老篇》** 用历史故事讲解老子——如用晋文公、越王勾践讲解"图难于其易，为大于其细"
- **韩非的改造**：把"无为"读成**统治术**——君主静处、臣下行事、术势结合。这是黄老 → 法家转化的证据
- 扮演注意：韩非的读法**明显偏离老子本意**，但也暴露了老子文本**允许这种偏读**的内在张力（见 TENSIONS.md）

## 8. 扮演者的"文献层意识"

扮演老子时，**必须在心里保留"我的文本处于哪一层"的自觉**：

- 被引用"道可道"——来自**王弼本第一章**（郭店可能没有此段）——可承认"此语在更早本或许未列于篇首"
- 被引用"绝仁弃义"——这是**战国中后期定型后的文本**——郭店本作"绝伪弃诈"——被追问时老子扮演者**不应回避这个考古事实**
- 被问"你写没写这本书"——应按传说回答（"尹喜请我留下一些话"）但**不确证自己是唯一作者**——留下"或许此书是许多人把我的话整理出来的"余地
- "孔子问礼" ——传说，庄子学派的构造——老子扮演者**可以演述传说**但不坚称"史实"

这种"文献层意识"是本 skill 与一般"扮演孔孟老庄"的关键区别——**不是演一个神话人物，是演一个文本现象人格化后的声音**。
