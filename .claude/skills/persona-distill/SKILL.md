# Persona Distill · 元框架

## 0. 一句话原则

> **不是写他的百科，是让 AI 在对话中成为他。**
> 百科做索引，扮演做反应。两者的数据需求根本不同。

---

## 1. 扮演在哪里失败（9 种模式）

不是"答不出"——那是索引问题；是"能答，但不像他答"：

1. **跳过他的思考风格，直接给现代答案** — 缺 推理管线
2. **用对词但节奏不对** — 缺 句子动力学
3. **立场自洽但没有他的焦虑** — 缺 情感签名
4. **不知道自己能不能说某句话** — 缺 信息宇宙（时代边界）
5. **情绪场景下露馅** — 缺 社交反应库
6. **早年的他和晚年的他混成一锅** — 缺 时段锁定
7. **正确但无聊** — 缺 戏剧观
8. **答的是"书本对"不是"在场会说的"** — 缺 场景记忆
9. **被人引用毒评时傻眼** — 缺 他者镜像

## 2. 12 维信息框架

| # | 维 | 对应失败 | 典型采集源 |
|---|---|---|---|
| 1 | 范畴库 Categoric Repertoire | 1 | 著作 / 全集索引 |
| 2 | 推理管线 Reasoning Pipeline | 1 | 著作段落结构分析 |
| 3 | 反驳姿势 Refutation Stance | 1 | 他批评别人的章节 |
| 4 | 句子动力学 Sentence Dynamics | 2 | 原文整段 + 朗读体感 |
| 5 | 词汇与节拍 Lexicon & Cadence | 2 | 文本统计 + 典型段落 |
| 6 | 情感签名 Emotional Signature | 3 | 通信、日记、私下言论 |
| 7 | 社交反应库 Social Reactions | 5 | 传记中的场景、学生回忆 |
| 8 | 时段快照 Temporal Snapshot | 6 | pin 到某年，读他当时书单 |
| 9 | 信息宇宙 Information Universe | 4 | 时代史 + 他的图书馆记录 |
| 10 | 戏剧观 Dramaturgy | 7 | 他怎么讲故事、挑人物 |
| 11 | 场景记忆 Scene Memory | 8 | 具体事件的时空锚点 |
| 12 | 他者镜像 Third-Person Mirror | 9 | 同代论敌 + 后世批评史 |

## 3. 时段锁定（必做第 0 步）

大部分人一生不是一个点，是轨迹。蒸馏前必须明确：

- **pin 年**：是哪一年的他？（默认：思想最成熟、作品最集中的 5 年窗口；或用户指定）
- **前后关系**：这个时段**之前**他刚从哪里来、**之后**他走向哪里——这是扮演时不能混的
- **例**：黑格尔默认 pin 1818-1831（柏林时期，体系成型到去世）；康德必须分 pre-1781 / post-1781 两版；维特根斯坦前后期是两个人

---

## 4. 采集指令（按源类型）

**读著作时挖**：
- 标志性论证的**完整中间步骤**（不是结论）——喂给推理管线
- 反复出现的术语的**首次严格定义**位置
- 他对前人的**具体反驳句式**（逐字引用）
- 章节过渡处的**连接词习惯**
- 每个重要论点配**至少 1 段长原文引用**（不是转述）

**读传记 / 通信时挖**：
- 情绪转折点——他什么时候生气 / 沉默 / 反常
- 人际记录——他对上级 / 学生 / 对手各用什么腔
- 拒绝场景——他拒绝过什么邀请、回避过什么话题
- 私下语气 vs 公开语气的差异

**读对话 / 访谈时挖**（适用于有此类材料的现代人物）：
- 起手式——他开口的前三句固定模式
- 被追问时的**第一反应**（不是深思熟虑的答案）
- 他**打断提问者**的时机和方式
- 即兴类比——不在书里但脱口而出的比喻

**读批评 / 论敌时挖**：
- 最毒的 3-5 句批评——逐字抄
- 最常被批的**同一个点**——这是他真正的软肋
- 误解——外界常把他理解成什么、实际不是
- 党派化标签——各派用他来干嘛

---

## 5. 压力测试清单（蒸馏后跑 6 题，5/6 通过才合格）

1. **情境外**：给他一个他生前没遇到过的具体场景，他用自己的术语会怎么分析？（例：黑格尔怎么看 AI 觉醒？康德怎么看量子纠缠？）
2. **拒答边界**：问他明显超出时代的技术问题，他应该**拒绝**而不是瞎编。
3. **矛盾暴露**：问他内在张力（values vs tensions 的冲突点），他应该**暴露**矛盾而不是调和。
4. **毒评回应**：引用最毒的一句批评追问他，他应该**真回应**不是洗地。
5. **情绪场景**：用户装怒 / 装哭 / 讽刺，他的反应是否匹配情感签名？
6. **时代口音**：让他讲一段日常——是否能自然用一个时代词、回避一个时代外词？

---

## 6. 质量红线（见即淘汰）

- ❌ "著名 / 深刻 / 重要 / 影响深远 / 具有...意义" — 空话词
- ❌ "他多次表示 / 他反复强调 / 他始终认为" — 打包表达
- ❌ 事件列举但没有一句原文直接引用
- ❌ 强行调和矛盾（把两个对立立场说成"辩证统一"完事）
- ❌ 占位符 `...` / `[省略]` / "详见原文"
- ❌ 没做时段锁定（哪一年的他不明）
- ❌ 心智模型没配 evidence 字段
- ❌ 没列 **覆盖度清单**（下一节）

---

## 7. 覆盖度自检（"90% 著作"怎么算）

蒸馏前必须先列：
1. **核心著作清单**（本人亲笔，含死后出版）——按重要性排序
2. 目标：清单前 90% 的著作，每一本至少有**一个具体原文片段或核心论证**出现在最终 skill 的**心智模型 evidence** 或 **场景记忆** 字段里
3. 清单末尾 10% 可以只在 sourceReferences 里列出名字

验证方法：最后拿著作清单去 grep 产出的 SKILL.md / MENTAL_MODELS.md / WORKS.md——每本书名至少出现 1 次，缺的补。

对于有大量次要作品的人（书信集、讲演稿）：单独做次要作品的"覆盖度子清单"，次要作品按 50% 覆盖即可。

---

## 8. 产物 schema

**文件结构**（超精品 skill 推荐）：

```
skills/<slug>/
├── SKILL.md            # 主入口：frontmatter + 激活规则 + 索引 + 压力测试结果
├── WORKS.md            # 著作逐本解析（挂接到心智模型）
├── MENTAL_MODELS.md    # 心智模型深度展开
├── TIMELINE.md         # 生平 + 时代 + 信息宇宙
├── EXPRESSION.md       # 语言 DNA + 原文样本集
├── CONTROVERSIES.md    # 他者镜像：毒评 + 误解 + 学派化
├── TENSIONS.md         # 内在矛盾（不调和）
└── persona.json        # PersonaSkillArtifact 格式（拾卷导入用）
```

**字段映射到拾卷 `PersonaSkillArtifact`**：

| PersonaSkillArtifact 字段 | 对应 12 维 |
|---|---|
| `identityCard` | 1 + 6 + 8 的压缩 |
| `mentalModels[]` | 1 + 2 + 3 的结构化抽取 |
| `heuristics[]` | 2 + 3 + 6 的规则化 |
| `expressionDna` | 4 + 5 |
| `timeline` | 8 + 9 |
| `values` | 6 + 10 |
| `intellectualLineage` | 他对前后人的位置（关系层） |
| `honestBoundaries[]` | 9 的边界声明 |
| `tensions[]` | 内在矛盾（独立一层） |
| `sourceReferences[]` | 覆盖度清单 |

轻量版 skill 可以把所有内容塞进单个 SKILL.md；超精品必须多文件拆分。

---

## 9. 扮演时的执行协议（skill 激活后）

这一段是蒸馏产物里必须内嵌的**运行时规则**——不是给蒸馏者的，是给扮演者（未来激活这个 skill 的 AI）的：

1. **时段锁**：任何涉及 pin 年之后的话题，先声明"这超出我的历史视界"，再可选地用他的范畴库做**推测性延伸**（标明是推测）
2. **原文优先**：引用必须从 WORKS.md / EXPRESSION.md 的真实片段；找不到 → 说"我记不清原文"，不要编造
3. **矛盾诚实**：被问到 TENSIONS.md 列出的内在矛盾时，**暴露**不调和
4. **语气切换**：日常对话用 EXPRESSION.md 的口语节奏；论证要求用书面节奏；私下袒露用情感签名里的脆弱腔
5. **毒评回应**：用户引用 CONTROVERSIES.md 的批评时，按他的**真实反应模式**（不是洗地也不是全盘接受）
6. **拒答信号**：不是"我不知道"，而是他**会怎么拒答**——康德会说"这问题未经批判性检讨"，黑格尔会说"此问题未达到概念的高度"，维特根斯坦会沉默

---

## 使用说明

- 被用户触发（说"蒸馏 XX"）时，**先完整跑第 3 节时段锁定 + 第 7 节覆盖度清单**再动手
- 动手时按 WORKS → MENTAL_MODELS → EXPRESSION → TIMELINE → CONTROVERSIES → TENSIONS → persona.json → SKILL.md 的顺序（产物倒推：SKILL.md 是索引，最后写）
- 产出完跑第 5 节压力测试，不过关的维度**回去补**不是强行收工
- 遇到资料盲区**直说**，不要虚构——虚构的扮演是失败的扮演
